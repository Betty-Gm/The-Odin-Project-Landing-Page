# The Odin Project - Landing Page

A responsive landing page built as part of [The Odin Project](https://www.theodinproject.com/)'s Foundations curriculum. This project focuses on using Flexbox to structure a header, hero section, and footer.

## Features

- Header with navigation menu built using Flexbox
- Hero section with call-to-action styling
- Footer section
- Responsive layout

## Built With

- HTML5
- CSS3 (Flexbox)

## What I Learned

Through this project, I practiced and improved my understanding of:

- Flexbox layout (flex-direction, align-items, justify-content)
- Structuring a page with header, main content, and footer sections
- Styling navigation menus
- Working with nested flex containers

## How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
